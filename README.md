# Order and Product Management Microservice

Этот проект представляет собой микросервис для управления заказами и продуктами с использованием **Clean Architecture**. Система позволяет выполнять CRUD-операции с продуктами, создавать и отменять заказы, управлять запасами и поддерживает функциональность **soft delete** для продуктов.

## Описание

Микросервис предоставляет API для следующих операций:

- **CRUD с продуктами**: создание, обновление, логическое удаление (soft delete).
- **Управление заказами**: создание и отмена заказов.
- **Управление запасами**: увеличение и уменьшение количества товаров при заказах.
- **Поиск заказов и продуктов**: возможность поиска по различным параметрам.

### Требования

- .NET 6.0 или выше

### Шаги для установки:

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/anna-andreikovets/shopcore.git
    ```

2. Перейдите в каталог проекта:
    ```bash
    cd shopcore
    ```

3. Восстановите зависимости:
    ```bash
    dotnet restore
    ```

4. Запустите проект:
    ```bash
    dotnet run
    ```
